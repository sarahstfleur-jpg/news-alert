News Alert

A lightweight, automated Python tool that delivers topic-based news updates directly to your Windows desktop. 

By fetching Google News RSS feeds tailored to your specific interests, the app sends clean, native notifications with clickable headlines—allowing you to jump straight to the source article in your browser with a single click.

Key Features
* Custom Topic Tracking:** Filters headlines based on user-defined keywords (e.g., AI, Politics, Gaming) saved locally in a JSON file.
* Clickable Desktop Alerts:** Built with 'win11toast' for native Windows notifications that open directly in your default browser when clicked.
* Interactive Preferences:** Uses a lightweight 'tkinter' interface to easily set or update your topics anytime.
* Zero Cost & No Setup Required:** Uses free Google News RSS feeds with no API keys or subscription fees required.
